# 🤖 Human-Robo Simulation #

A Python-based simulation where a Human and a Robot work together in an industrial environment. The Robot automatically moves to the cooling zone when it overheats, showing real-time human-robot collaboration.

# ✨ Features #
- Real-time 2D Simulation using Pygame
- Human & Robot characters with movement
- Smart Robot: Automatically goes to Cooling Zone when temperature is high
- Temperature / Heat management system
- Interactive industrial environment

# 🛠️ Tech Stack #
- Python 3.13
- Pygame
